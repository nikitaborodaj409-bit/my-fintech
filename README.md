# My Fintech

**My Fintech** — долгосрочный проект Никиты по проектированию финансовой платформы с нуля.

Проект одновременно является:

- тренажёром системного, solution и domain-архитектора;
- практическим pet-project с архитектурой, моделями, API и кодом;
- исследованием продуктовой идеи;
- возможной основой будущего fintech-бизнеса.

## Цели

- Понимать fintech end-to-end: от потребности клиента и движения денег до систем, данных и эксплуатации.
- Самостоятельно принимать и защищать архитектурные решения.
- Проверять важные утверждения по стандартам, первоисточникам и международной практике.
- Постепенно довести архитектуру до работающего прототипа.
- Сохранять историю решений и не восстанавливать контекст заново при каждом обсуждении.

## Рабочий цикл

**Проблема → гипотеза Никиты → исследование → проверка по источникам → решение → фиксация в проекте → следующая проблема.**

ChatGPT действует как наставник, исследователь и хранитель структуры. Архитектурные решения обсуждаются с Никитой и не подменяются готовой «идеальной архитектурой».

## Текущий этап

**Fintech v0.0 — Customer + Money**

Первый сценарий: человек передаёт fintech 1 000 000 UZS и видит эту сумму в приложении. Мы должны выяснить, что это означает юридически, экономически и технически.
