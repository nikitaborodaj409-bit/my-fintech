# Architecture Decision Records

Здесь хранятся принятые архитектурные решения и причины их принятия.

## Статусы

- Proposed
- Accepted
- Superseded
- Rejected

## Шаблон ADR

```markdown
# ADR-NNN: Название

## Status

Proposed

## Context

Какую проблему решаем и какие ограничения известны.

## Decision

Какое решение принято.

## Consequences

Положительные и отрицательные последствия.

## Alternatives

Какие варианты рассматривали и почему не выбрали.

## Evidence

Источники, стандарты, реализации и наши гипотезы.
```

ADR создаётся только после обсуждения и принятия решения. Открытые вопросы остаются в backlog.
