# Glossary

Словарь фиксирует значения терминов именно в контексте My Fintech. Определения уточняются по мере развития проекта.

| Термин | Рабочее определение | Статус | Основание |
|---|---|---|---|
| Fintech | Проектируемая цифровая финансовая платформа; точная бизнес- и юридическая модель ещё не выбрана | Гипотеза | Видение проекта |
| Balance | Пока только сумма, отображаемая человеку; экономический смысл и источник истины ещё предстоит определить | Открытый вопрос | Problem #001 |
| Customer | Пока не зафиксирован: человек становится клиентом только после определения условий отношений с fintech | Открытый вопрос | Problem #001 |
| Account | Не вводим автоматически; необходимость и смысл должны быть выведены из сценариев | Открытый вопрос | Принцип проекта |
| Ledger | Кандидат на механизм финансового учёта; ответственность ещё не зафиксирована | Открытый вопрос | BIAN / industry practice |

## Правила словаря

- Не считать похожие слова синонимами без проверки.
- Для каждого важного определения указывать источник или помечать его как гипотезу.
- При изменении смысла сохранять причину в ADR.
